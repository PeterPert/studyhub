# Telegram-бот StudyHub

Работает вместе с FastAPI (`main.py`): те же логины/пароли, расписание и уведомления студентов.

## Настройка

1. **Токен бота** — только через переменную окружения (не коммитьте токен в git):

   В файле `back/.env` (рядом с `main.py`) добавьте:

   ```env
   TELEGRAM_BOT_TOKEN="8633452808:AAFQd9wMQuMQpPAtftQ-x-nK0UPYu4ogDvo"
   API_BASE_URL=http://127.0.0.1:8000
   ```

   Если токен уже где-то засветился — перевыпустите его в [@BotFather](https://t.me/BotFather).

2. Установите зависимости (из папки `back`):

   ```bash
   pip install -r requirements.txt
   ```

3. Запустите API в одном терминале:

   ```bash
   uvicorn main:app --reload --host 127.0.0.1 --port 8000
   ```

4. Запустите бота во втором терминале (из папки `back`):

   ```bash
   python -m tg_bot.bot
   ```

   Остановка: **Ctrl+C**.

## Возможности

- `/start` — вход (логин и пароль как на сайте).
- Кнопка **«Расписание на сегодня»** — для студента и преподавателя.
- Студентам: напоминание примерно за 10 минут до пары (по расписанию на сегодняшнюю дату).
- Студентам: новые уведомления с сайта дублируются в Telegram (опрос каждые 30 с).
- `/logout` — выход из бота.

Данные привязки чата хранятся в `tg_bot/tg_bot_data.sqlite`.

## Не пускает student1 / 123 или «HTTP 503»

1. В браузере откройте **`http://127.0.0.1:8000/api/health`** — должно быть `{"ok":true,...}`. Если ошибка — API или база не работают.
2. Запустите API: из папки `back` выполните `uvicorn main:app --host 127.0.0.1 --port 8000`.
3. **503** чаще всего из‑за **PostgreSQL**: в `.env` указан `DATABASE_URL`, но сервер БД не запущен или неверный пароль.  
   **Вариант А:** запустите PostgreSQL и проверьте `DATABASE_URL`.  
   **Вариант Б (проще для ПК):** **удалите или закомментируйте** строку `DATABASE_URL` в `back/.env` — тогда API сам возьмёт **SQLite** (`back/studyhub_local.db`). Затем из `back`: `python seed.py`.
4. В `.env` у бота: `API_BASE_URL=http://127.0.0.1:8000` (без `/api` в конце).
5. Пользователи `student1` и т.д. появляются после **`python seed.py`** в той же БД.

Бот подгружает `back/.env` автоматически.
