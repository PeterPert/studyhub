# StudyHub Frontend

React + TypeScript + Vite + Framer Motion

## Запуск

1. **Бэкенд** должен работать на `http://127.0.0.1:8000`

2. Установка и запуск фронта:

```bash
cd front
npm install
npm run dev
```

Приложение откроется на http://localhost:5173

Vite проксирует `/api` на бэкенд, поэтому запросы к API работают автоматически.
